# 03 — Feature & Leakage Audit

Create a feature inventory.

For each candidate predictor record:

| Feature | Available at prediction time? | Leakage risk | Decision | Rationale |
|---|---|---|---|---|
| | | | | |

Classify each as:
- Include
- Exclude
- Conditional / requires justification

Pay particular attention to:
- final response variables;
- appliance counts;
- arrival/attendance measures;
- fields generated after mobilisation;
- target-derived values.

The final modelling feature set must be defensible.
