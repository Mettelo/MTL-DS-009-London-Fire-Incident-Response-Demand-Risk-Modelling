# 06 — Evaluation & Thresholds

Document:
- train/validation/test strategy;
- temporal holdout where possible;
- class distribution;
- precision;
- recall;
- F1;
- PR-AUC;
- ROC-AUC where useful;
- confusion matrices;
- calibration;
- threshold comparison.

Explicitly discuss the operational consequence of:
- false positives;
- false negatives.

Do not assume 0.50 is the correct threshold.
