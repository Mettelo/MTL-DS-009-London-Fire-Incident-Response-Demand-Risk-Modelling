# 08 — Operational Interpretation

Translate predicted probabilities into an analytical planning view.

Possible bands:
- lower predicted response demand;
- medium predicted response demand;
- higher predicted response demand.

Do not copy these thresholds blindly.

Derive and document the final boundaries using model performance and the project's stated use case.

These are **analytical risk bands**, not official London Fire Brigade dispatch categories.

Document:
- threshold;
- precision/recall at threshold;
- expected false-positive/false-negative trade-off;
- intended planning use;
- prohibited use.
