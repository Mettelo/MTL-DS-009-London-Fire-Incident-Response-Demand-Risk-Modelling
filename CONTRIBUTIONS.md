## Working agreement
Teams should:
- create issues for substantive work;
- use scoped branches;
- make meaningful commits;
- open pull requests;
- review each other's work;
- avoid one final bulk upload.

## Example branches
- `feature/incident-mobilisation-join`
- `analysis/class-balance-eda`
- `feature/leakage-audit`
- `model/logistic-baseline`
- `model/xgboost`
- `evaluation/threshold-selection`

## Example commits
- `feat: build incident-level mobilisation aggregates`
- `analysis: profile high-response target`
- `fix: remove post-response leakage fields`
- `model: add weighted logistic baseline`
- `eval: compare operational thresholds`
